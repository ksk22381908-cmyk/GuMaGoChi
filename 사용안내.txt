GuMaGoChi 0.2.5 · 게임 내 업데이트·달리기 배율 수정 버전

1. ZIP 전체를 원하는 폴더에 압축 해제하세요.
2. GuMaGoChi.exe를 실행하세요. assets 폴더를 함께 유지해야 합니다.
3. 첫 아기의 이름을 지으면 바탕화면 아래쪽에 나타납니다.
4. 고구마 우클릭으로 먹이, 치료, 놀이, 훈련, 집, 비활성화를 선택합니다.
5. 몸을 바로 드래그해서 옮길 수 있습니다. 쓰다듬기는 우클릭 메뉴에서 선택합니다. 고구마는 혼자 걷고 쉬며 방향을 바꿉니다.
6. 배설물은 직접 클릭해 치웁니다. 흙더미로 들어가면 클릭해 성장시킵니다.
7. 공 활동은 공을 뒤로 당겼다 놓으면 고구마가 쏩니다. 3회 한 세트입니다.
8. 트레이 고구마 아이콘을 클릭해 집을 열고, 우클릭으로 일시정지·종료합니다.
9. Space + E 동시 누르기 또는 고구마·트레이 우클릭의 비상탈출은 상태를 저장하고 즉시 종료합니다. 활성 상태는 그대로 유지합니다. 다른 프로그램이 앞에 있어도 단축키가 감지됩니다.
10. 고구마·트레이 우클릭의 캐릭터·UI 비율에서 10~200%를 10% 단위로 선택합니다. 배율은 저장되며, 활동·달리기·디펜스 전투 중에는 변경할 수 없습니다. 아주 작은 배율에서도 트레이 메뉴는 기본 크기로 유지되어 복구할 수 있습니다.

11. 트레이 우클릭 또는 집의 저장·사용 안내에서 업데이트 확인을 선택합니다. 새 버전이 있으면 다운로드 및 설치를 누릅니다. 저장 후 종료하고 설치 후 다시 실행하며 육성 데이터는 유지합니다. 쓰기 가능한 폴더에 설치하세요. 이전 파일 백업은 %LOCALAPPDATA%\GuMaGoChi-Updater 아래에 남습니다. v0.2.4 이하에서는 이번 버전을 한 번 수동으로 받아야 합니다.

수치는 낮을수록 양호합니다. 먹이는 5분, 치료는 10분 쿨타임을 공유합니다.
아기는 성장 경험치 180 EXP(자동 누적 3시간)에 성장하고, 모든 개체는 활성 실행 100시간에 자연사합니다.
종료·절전·화면 잠금·전체 화면 작업·비활성·성장 대기 중에는 육성 시간이 멈춥니다.
집 창을 닫는 것은 일시정지가 아닙니다. 활성 개체는 계속 돌봐야 합니다.

저장: %LOCALAPPDATA%\GuMaGoChi\save.json
자동 저장과 이전 저장본 백업을 제공합니다.
다른 PC로 옮길 때는 집의 ‘저장 · 사용 안내’에서 내보내기·가져오기를 사용하세요.
네트워크 연결과 계정 없이 사용할 수 있습니다.

환경: Windows 10/11, .NET Framework 4.8 이상
아기 이동·식사·공 발사·땅속 성장 준비 모션과 땅속 집 배경을 제공합니다. 대기는 기준 이미지를, 수면은 눈 감은 전용 모션을 사용합니다.
3단계 성장, 집 꾸미기, 추가 훈련은 후속 개발 항목입니다.
게임 밸런스 수치는 초기값이며 실제 플레이를 통해 조정할 예정입니다.

육성 개선: 놀이·훈련·쓰다듬기 쿨타임 3분. 쓰다듬기 피로 +1. 골인 즉시 씨앗 +1, 완료 기본 보상 +8.
성장 영양제는 씨앗 30개로 구매 후 아기 행동 메뉴에서 사용합니다. +30 EXP이며 나이는 변하지 않습니다.
이전 저장 파일은 자동 전환됩니다. 전환 후에는 새 EXE를 사용하세요.
골인 훈련: 3회 모두 성공 → 5회, 5회 모두 성공 → 7회. 골인당 씨앗 +1/+2/+3, 기본 완료 +8은 첫 단계만 지급합니다.
현재 점수·최고 기록은 좌측 상단에 표시하며 최종 기록 화면은 닫을 때까지 유지됩니다. 골대 상단 선에 공이 닿으면 골인입니다.
공 가져오기 중 다른 고구마에게 공을 맞히면 성격별 대사와 모션으로 반응합니다.
[맛탕 만들기]
고구마 우클릭 또는 집의 개체 행동 메뉴 → 맛탕 만들기 → 이름 확인 후 승인.
선택한 개체와 돌봄 기록은 삭제되고 추억 앨범에는 남지 않습니다. 도감·씨앗·공용 가방은 유지합니다.

[고구마 버러지 디펜스]
집 → 버러지 디펜스 → 편성하기. 보유 목록에서 우측 하단 1~5번 칸으로 드래그하세요.
시작 이미지 클릭: 스킵 / 고구마 클릭: 스킬 / 우클릭: 능력치 / Shift+클릭: 공격 표식 켜기·끄기.
매 라운드 완료 시 강화 카드 3장 중 1장을 선택합니다. 강화는 이번 전투에서만 유지됩니다.
10마리 처치마다 씨앗 1개. 디펜스 중 육성 시간은 멈춥니다. 상세 안내는 함께 포함된 디펜스-구현-사용안내.md를 참고하세요.
