# 당근마 디자인 개선

당근마(26번)는 새싹, 자주색 고구마 몸체, 주황 멜빵바지와 초록 잎 장식을 사용합니다.
`carrot-atlas.png`는 1024×1536, 4열×6행의 투명 배경 시트입니다.
위에서부터 대기·이동·먹기·공 던지기·수면·땅 파기이며 각 동작은 4프레임입니다.

2차 진화는 기존 행동 메뉴의 선택 기능을 사용합니다. 나이·육성 기록·당근마의 전투 수치는 유지합니다.

- 농부마(진화 10): 밀짚모자와 당근 바구니. 바구니에서 당근을 꺼내 던집니다.
- 황달마(진화 11): 얼굴 영역만 노르스름한 통통한 고구마. 먹던 당근 조각을 입으로 뱉습니다.

진화 시트는 `../evolutions/farmer-atlas.png`, `../evolutions/hwangdal-atlas.png`이며 같은 4열×6행 순서입니다.
디펜스의 일반 공격과 5연속 스킬, 공 놀이·훈련의 투사체도 각각 통당근과 당근 조각으로 표시합니다.
황달마의 이름은 캐릭터 설정입니다. 당근 섭취로 인한 노란 피부색은 실제 황달과 다른 카로틴혈증에 해당합니다.

생성 이미지 특성상 프레임 간 세부 무늬·소품 위치 차이가 남아 있습니다.
