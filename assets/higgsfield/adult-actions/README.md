# 성체 30종 액션 시트

Higgsfield GPT Image 2.5로 각 adults-v2 디자인을 참조해 생성했다. 캐릭터마다 하나의 1024×1024 PNG에 네 가지 동작을 묶어 총 30회 생성했다. 별도 재생성은 하지 않았다.

4열×4행, 셀 256×256. 행 순서는 걷기 / 먹기 / 공 쏘기 / 땅속 들어가기이며 각 동작은 4프레임이다. 왼쪽부터 오른쪽으로 재생한다. 공은 게임에서 별도로 그린다.

preview.html을 브라우저에서 열어 30종의 동작을 비교할 수 있다. manifest.json은 종 번호·이름·참조 디자인·생성 출처·프레임 구성을 기록한다.

모션 초안으로 EXE에는 아직 적용하지 않았다. 생성 원본의 반투명 잔광, 프레임 정렬·크기 편차, 장식의 일부 변형은 적용 전에 확인·정리해야 한다. 대기·수면은 기존 정면 디자인과 공통 연출을 사용한다.
