# 눈 감고 자는 수면 프레임

Higgsfield GPT Image 2.5로 아기 기준 이미지와 성체 30종의 개별 디자인을 참조했다. 각 캐릭터에 2×2, 4프레임 시트 하나씩 총 31개. 모든 프레임은 눈을 감은 수면과 작은 호흡을 표현한다.

원본 시트 1024×1024, 셀 512×512. 왼쪽에서 오른쪽, 위에서 아래 순서로 2fps 반복 재생한다. EXE에서 반투명 잔광을 제거하고 크기와 발 기준선을 정렬하며 원본 종횡비를 유지한다. v0.1.11에 적용.

baby-sheet.png는 아기, 00-sheet.png~29-sheet.png는 Catalog 성체 번호다. 생성 출처는 manifest.json, 전체 확인은 overview.png.
