# 베리마와 2차 진화체

- 기존 캐릭터 ID 5는 베리마로 이름을 변경하고 딸기 케이프 디자인을 적용했습니다.
- 진화 ID 8: 블루베리마. 이동할 때 몸체가 회전합니다. 블루베리 투척 명중 후 3초 동안 초당 4의 독 피해를 적용합니다. 재명중 시 지속시간이 갱신됩니다.
- 진화 ID 9: 라즈베리마. 기본 공격으로 1초 동안 과즙 빔을 발사합니다. 빔 경로의 적에게 기본 공격력의 2배에 해당하는 총 피해를 나누어 적용합니다.
- 각 캐릭터는 대기, 이동, 먹기, 공격, 수면, 땅 파기 6종 동작을 사용합니다.
- 베리마의 우클릭 메뉴에서 `2차 진화 선택`으로 선택합니다. 기존 나이와 돌봄 기록은 유지됩니다.

에셋은 OpenAI ImageGen으로 생성한 투명 배경 4열 × 6행 아틀라스입니다. 전투 열매·독·과즙 빔은 게임의 픽셀 렌더러로 표시합니다.

## 먹기 모션 중복 팔 수정

OpenAI 내장 ImageGen으로 `blueberry-eat-corrected.png`와 `raspberry-eat-corrected.png`를 생성했습니다. 게임은 해당 아틀라스의 세 번째 행(먹기 4프레임)만 사용합니다. 나머지 동작은 기존 아틀라스를 사용합니다.

수정 프롬프트: 세 번째 행의 네 먹기 프레임에서 몸 양옆에 남은 대기 자세의 팔을 제거한다. 팔은 컵을 잡는 두 팔만 남긴다. 컵, 얼굴, 발, 색상, 픽셀 스타일, 프레임 배치와 투명 배경을 유지한다.
