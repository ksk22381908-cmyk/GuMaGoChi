# 왕구마와 2차 진화 디자인

확정 A안의 왕구마, 근육질 왕고구마, 최신 거지왕 디자인의 망했구마를 사용합니다.

- `king-atlas.png`: 왕구마 기본 모습
- `../evolutions/king-muscle-atlas.png`: 왕고구마(진화 ID 12)
- `../evolutions/king-beggar-atlas.png`: 망했구마(진화 ID 13), 공격 행은 손으로 쓰레기를 던지는 동작으로 수정

각 시트는 투명 배경 1024×1536, 4열×6행입니다. 위부터 대기·이동·먹기·공격/공 던지기·수면·땅 파기이며 각 동작은 왼쪽부터 4프레임입니다. 행 경계의 투명 구간을 찾아 새싹·왕관·소품이 잘리지 않게 분리합니다.

왕고구마의 충격파와 망했구마의 쓰레기·낙하 바가지·파편은 `RoyalCombat.cs`에서 게임 좌표에 맞춰 렌더링합니다. 반경과 기절은 실제 전투 판정에 연결됩니다. 생성 이미지 특성상 프레임 사이 소품과 무늬의 작은 차이는 남아 있습니다.
