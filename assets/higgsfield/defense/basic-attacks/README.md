# 31종 기본 공격 이펙트

상태: GuMaGoChi v0.2.0 디펜스에 적용. 배포 ZIP에는 실행용 프레임과 manifest를 포함한다.

- `00`부터 `30`까지 폴더명은 `src/Model.cs`의 SpeciesId와 일치한다.
- 각 폴더의 `00.png`는 투사체 또는 지점 예고 표시다.
- `01.png`, `02.png`, `03.png`는 명중 시작 → 최대 효과 → 소멸 단계다.
- 모두 256×256 투명 RGBA PNG이며 `atlas.png`는 4열 1행이다.
- `manifest.json`의 trajectory는 straight / parabolic / point로 구분한다.
- 궤적, 속도, 사거리, 충돌 및 피해는 프로그램에서 구현한다.
- 캐릭터 본체는 기존 공던지기 모션을 재사용한다. 대사는 프로그램 말풍선으로 표시한다.
- 당근마와 간첩마는 승인된 시범 시안 프레임을 재사용했다.
- 이번 묶음은 기본 공격용이다. 31종 고유 스킬의 별도 디자인을 모두 만든 것은 아니다.
- 당근마 스킬은 src/Defense.cs에서 160ms 간격으로 다섯 번 순차 발사한다.

## 검수

5개 원본 시트의 실제 그림 행을 탐지한 후 각 열의 영역을 분리했다.
종별 네 프레임에 공통 비율을 적용하고 원본의 크림/흰 배경과 설명 문구를 제외했다.
외부 배경에 연결된 흰 영역만 투명화해 뼈·얼음 등의 내부 흰 하이라이트를 유지했다.
31종 ID, 124개의 비어 있지 않은 프레임, 프레임 여백, 시트 구성을 검사했다.
`review-1.png`부터 `review-4.png`는 투명화된 최종 프레임 검수표다.
`all-31-preview.gif`와 `preview-1.gif`부터 `preview-6.gif`는 디자인 미리보기다.

재생 타이밍은 시범 설정이며 실전 밸런스나 기존 디펜스 게임 구현을 의미하지 않는다.
