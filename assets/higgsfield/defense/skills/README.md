# 31종 고유 스킬 이펙트

상태: GuMaGoChi v0.2.0 디펜스에 적용. 배포 ZIP에는 실행용 프레임과 manifest를 포함한다.

- 폴더 `00`부터 `30`까지는 `src/Model.cs`의 SpeciesId와 일치한다.
- 종별 `00.png`~`03.png`는 384×384 투명 RGBA 프레임이다.
- `atlas.png`는 4열 1행(1536×384)이다.
- 투사형은 `00.png`가 단일 투사체, 나머지는 명중 시작 → 최대 효과 → 소멸이다.
- 비투사형은 발동 예고 → 형성 → 최대 효과 → 소멸이며, 지속 스킬은 최대 효과 프레임을 사용해 프로그램에서 유지한다.
- `manifest.json`의 type으로 자신 강화·아군 강화·보호막·회복·지점 발생·장판·투사형을 구분한다.
- 장판형은 bottom-center 앵커, 나머지는 center 앵커다.
- 캐릭터 본체와 말풍선은 이펙트에 포함하지 않는다. 기존 공던지기 모션과 프로그램 대사를 연결한다.
- 피해, 감속, 정지, 강화, 보호막, 회복, 쿨타임, 이동 궤적은 src/Defense.cs에서 구현한다.
- 당근마·간첩마는 승인된 시범 프레임을 재사용했다.
- 당근마는 한 발씩 160ms 간격으로 5회 발사한다. 해적마 3회·탐험마 5회·토끼마 10회도 단일 투사체의 순차 발사로 표현한다. 당근마 외 간격은 시범 미리보기 설정이다.
- 기획 수치는 아직 실전 밸런스 검증을 거치지 않은 추천안이다.

## 검수와 미리보기

원본 실제 그림 행과 각 행의 큰 공백을 찾아 프레임 경계를 분리했다.
31종 ID, 124개 비어 있지 않은 RGBA 프레임, 투명 모서리 및 프레임 여백을 검사했다.
`review-1.png`~`review-4.png`는 최종 프레임 검수표다.
`all-31-skills-preview.gif`는 전체 미리보기, `preview-1.gif`~`preview-6.gif`는 묶음별 미리보기다.
미리보기의 크기·재생 속도·효과 유지 시간은 디자인 검토용이며 실제 게임 수치와 다르다.
