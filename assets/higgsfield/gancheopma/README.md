# 간첩마 시안과 액션

둥근 감자가 고구마 행세를 하는 캐릭터. 수상한 눈빛, 황갈색 감자 몸, 테이프로 붙인 가짜 새싹. 최종 참조 시안은 design-round-draft.png.

actions-atlas-draft.png는 정지·걷기·먹기·공 쏘기·눈 감은 수면·땅속 들어가기 순서의 4열×6행, 총 24프레임 시트다. 정지와 수면을 같은 생성 시트에 포함해 몸의 비율을 일관되게 요청했다. 모든 동작을 동일한 스케일로 표시해야 하며 동작별 경계 상자에 별도로 꽉 맞추면 크기 차이가 다시 생긴다.

실제 생성 크기는 1360×2048로 세로 셀 경계가 정수가 아니므로 manifest.json의 프레임 좌표를 사용한다. 생성형 원본에 작은 포즈·윤곽 편차와 반투명 잔광이 있어 적용 시 검수가 필요하다. v0.1.12 EXE에 적용했다. 로딩 시 투명 잔광을 제거하고 모든 동작에 공통 크기 기준을 사용한다. 기존 다른 캐릭터 액션은 변경하지 않았다.
