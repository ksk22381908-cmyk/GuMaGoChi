# B안 꼬마 새싹

OpenAI ImageGen으로 만든 baby-b-atlas.png에 대기·걷기·먹기·공 던지기·수면·땅속 들어가기 각 4프레임, 총 24프레임이 들어 있습니다. 파란 컵은 먹기에만 나오고 공은 게임에서 별도로 그립니다.

게임은 실제 투명 영역으로 6개 행을 찾고, 공통 배율과 바닥 기준선을 적용합니다. 마지막 땅속 프레임은 작은 흙더미와 새싹입니다. 기존 아기 이미지·동작·수면 시트를 대체합니다. preview.html에서 동작을 볼 수 있습니다.

먹기 동작은 baby-b-eat-corrected.png의 세 번째 행을 사용합니다. 컵을 잡는 두 팔만 남기고 중복 팔을 제거했습니다.
