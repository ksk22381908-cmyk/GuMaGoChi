시트는 1024×1024이며 기본 셀은 256×256이다. 왼쪽에서 오른쪽, 위에서 아래로 읽는다. [preview.html](preview.html)을 로컬 브라우저에서 열어 프레임을 재생하거나 하나씩 확인할 수 있다.

## 제작 상태와 적용 전 확인

- 모든 이미지에서 투명 모서리를 확인했다. 다만 캐릭터 주변에 반투명 잔광이 남아 있어 바탕화면 적용 전에 정리가 필요하다.
- 생성형 시트이므로 프레임별 위치·크기와 기준선이 완전히 동일하지 않다. 일부 포즈는 셀 경계에 가까워 프레임 정렬·경계 확인이 필요하다.
- 걷기 동작은 짧은 발 움직임 중심이다. 게임 안의 위치 이동과 함께 사용한다.
- 이 자료는 모션 초안이며 현재 EXE에 적용되지 않았다.
- 대기·수면은 크레딧 부족으로 생성 요청이 제출되지 않았다.
- AutoSprite는 모델 목록에 있었으나 생성 도구가 해당 모델을 지원하지 않아 실제 작업은 제출되지 않았다. 일반 이미지 생성으로 프레임 시트를 제작했다. 자동 atlas는 제공되지 않는다.

기존 로컬 캐릭터를 외부로 전송하지 않고 새 아기 이미지를 생성했다. 모션 제작은 같은 Higgsfield 프로젝트 안의 신규 기준 이미지를 참조했다.
