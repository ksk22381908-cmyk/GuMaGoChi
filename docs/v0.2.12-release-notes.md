# GuMaGoChi v0.2.12

- Windows에서 실행할 때 `mscorlib`의 `System.Collections.Generic.Queue`를 찾을 수 없던 시작 오류를 수정했습니다.
- Microsoft .NET Framework 4.8 참조 어셈블리로 빌드해 Windows의 `System`에서 `Queue<T>`를 찾도록 교정했습니다.
- 당근마·농부마·황달마 디자인과 동작, 기존 저장 데이터는 유지합니다.

`GuMaGoChi-0.2.12-windows.zip`을 전체 압축 해제한 뒤 `GuMaGoChi.exe`를 실행하세요. EXE, `.config`, `assets`는 함께 유지해야 합니다. Windows 10/11과 .NET Framework 4.8 이상이 필요합니다.

이전 프로그램을 종료하고 새 폴더에서 실행하세요. 육성 저장 데이터는 `%LOCALAPPDATA%\GuMaGoChi`에 따로 보관되므로 앱 폴더를 교체해도 유지됩니다.
