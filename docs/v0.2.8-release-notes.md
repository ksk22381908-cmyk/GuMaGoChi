# GuMaGoChi v0.2.8

## 변경 파일 업데이트
- 변경되지 않은 설정·에셋의 크기와 SHA-256을 확인하고, 변경 파일만 들어 있는 소형 패치를 다운로드합니다.
- 파일이 누락·변경되었거나 패치가 없는 릴리즈는 전체 ZIP으로 업데이트합니다.
- 다운로드 체크섬과 실행 파일 버전 검증, 교체 전 백업, 설치 실패 시 복구를 유지합니다. 저장 데이터와 활성 상태는 유지합니다.
- 집 마릿수 안내 잘림 수정, 실행 시 집 창 자동 열기와 기존 게임 개선 사항을 포함합니다.

## 업데이트
v0.2.7 로컬 테스트 버전에서는 게임 안의 업데이트 확인 → 다운로드 및 설치로 소형 패치를 테스트할 수 있습니다.
v0.2.6 이하에서는 이 기능을 처음 받는 이번 업데이트만 전체 ZIP을 받으며, 이후부터 패치가 지원됩니다.
패치 기준 파일이 맞지 않으면 자동으로 전체 업데이트를 선택합니다. 오래된 에셋은 자동 삭제하지 않습니다.

## 배포
`package.ps1 -PreviousPackagePath <이전 배포 폴더>`로 생성합니다. 기본 기준은 release/GuMaGoChi-0.2.7-windows입니다.
전체 windows.zip과 .sha256, delta.zip과 .sha256, delta.json을 같은 정식 GitHub 릴리즈에 게시합니다.

## 검증
모델 테스트 12,230개, UI 프레임 744개와 UI·디펜스 렌더링 검증을 통과했습니다.
정상·누락·동일 크기 변조 파일, 경로 검증, 저장 보존과 변경 파일 단독 설치를 검증했습니다.
