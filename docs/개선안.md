# 개선안

개선안을 먼저 기록하고, 사용자가 일괄 반영을 요청하면 구현한다. Git 커밋·푸시·릴리스 업로드는 사용자가 별도로 요청할 때만 진행한다.

## 우선 반영할 확정 개선안

상태: v0.1.14 로컬 구현 완료, 144개 모델 검사 및 229개 UI 검사 통과. Git 반영: v0.1.14. 디펜스 개발은 이번 반영 범위에서 제외한다.

| 항목 | 현재 | 변경 확정 |
|---|---|---|
| 공 가져오기 보상 쿨타임 | 20분 | 3분 |
| 골인 훈련 완료 보상 쿨타임 | 20분 | 3분 |
| 골인 추가 씨앗 | 완료 시 쿨타임 조건으로 정산 | 쿨타임과 무관하게 골인마다 즉시 1개 |
| 훈련 완료 기본 씨앗 | 8개 | 8개 유지, 3분 쿨타임 적용 |
| 아기 → 성체 성장 조건 | 나이로 판정, 활성 실행 시간 8시간 | 나이와 별도인 성장 경험치로 판정, 자연 누적 3시간에 해당하는 기준 |
| 성장 영양제 | 없음 | 씨앗 30개로 구매, 먹이면 자동 누적 30분 상당 성장 경험치 증가, 나이·수명은 유지 |
| 쓰다듬기 실행 간격 | 교감 보상 15분 간격, 대사 반응은 반복 가능 | 3분에 한 번만 실행 |
| 쓰다듬기 피로 | 증가 없음 | 실행 시 피로 +1 (최대 100) |

놀이 완료 기본 씨앗 8개와 훈련·교감 보상 조건은 유지한다. 성장 준비 후 흙더미를 눌러 공개하는 방식과 100시간 수명도 유지한다. 완료 시 골인 추가 씨앗을 다시 정산하지 않아 중복 지급을 방지한다.

## 골인 즉시 보상

- 등록일: 2026-10-01
- 상태: v0.1.14 로컬 구현 완료 (Git 반영: v0.1.14)
- 확정 요청: 쿨타임과 관계없이 골인할 때마다 씨앗 1개를 즉시 지급한다.
- 현재: 3회 훈련 완료 시 보상 쿨타임이 끝나 있으면 기본 씨앗 8개에 골인 횟수만큼 추가 지급한다. 쿨타임 중에는 골인 추가 보상도 없다.
- 훈련 완료 시 기본 씨앗 8개 보상과 보상 쿨타임은 유지한다. 최신 합의에 따라 쿨타임은 3분으로 단축한다. 훈련·교감 기록 보상은 기존 규칙을 유지한다.
- 완료 시 골인 횟수에 따른 추가 씨앗 정산은 제거하여 즉시 보상과 중복 지급하지 않는다.
- 골인 씨앗은 성공 시점에 지급하며, 이후 훈련을 중단해도 이미 받은 보상은 유지한다.
- 일괄 반영 요청에 따라 로컬 EXE에 구현했다.

## 놀이·훈련 보상 쿨타임 단축

- 상태: v0.1.14 로컬 구현 완료 (Git 반영: v0.1.14)
- 공 가져오기와 골인 훈련 보상 쿨타임을 20분에서 3분으로 단축한다.
- 골인 즉시 씨앗 1개 지급에는 쿨타임을 적용하지 않는다.

## 수명과 성장 경험치 분리

- 상태: v0.1.14 로컬 구현 완료 (Git 반영: v0.1.14)
- 나이와 성장 경험치를 별도 값으로 관리한다.
- 나이는 활성 실행 시간에 따라 증가하고, 기존 100시간 자연사 수명 판정에 사용한다.
- 성장 경험치는 활성 실행 시간이 흐를수록 자동으로 증가한다. 자연 누적만으로 아기에서 2단계 성체까지 3시간이 걸리도록 성장 기준을 설정한다.
- 씨앗으로 성장 영양제를 구매하여 가방에 보관하고, 선택한 고구마에게 먹이면 아이템을 소모하여 성장 경험치를 증가시킨다. 구매만으로 경험치가 증가하지 않는다.
- 영양제 사용은 나이를 증가시키거나 수명을 줄이거나 늘리지 않는다. 경험치만으로는 교감·훈련 기록을 추가하지 않는다.
- 경험치가 성장 기준에 도달하면 성장 준비 상태가 된다. 성체 종류는 기존 교감·훈련 기록을 바탕으로 결정한다.
- 성장 준비 후 흙더미를 눌러 공개하는 기존 방식은 유지한다.
- 비활성화·프로그램 종료·일시정지 중에는 나이와 자동 경험치 누적이 모두 멈춘다.
- 성장 영양제 가격은 씨앗 30개, 사용 효과는 자동 누적 30분에 해당하는 성장 경험치로 확정한다. 성장에 필요한 자연 누적 3시간 기준의 1/6이다.
- 경험치 증가로 성장 기준에 도달하면 즉시 성장 준비 상태가 되고, 기존 흙더미 공개 연출을 따른다.
- 경험치 단위는 활성 실행 시간 분당 1 EXP, 성체 성장 기준은 180 EXP, 영양제 효과는 +30 EXP로 확정한다. 내부에서는 분 미만의 누적 시간도 보존한다.
- 영양제는 성장 준비 전 아기에게만 사용할 수 있으며, 별도 사용 쿨타임은 없다. 성체·성장 준비·사망 개체에게는 사용할 수 없다.
- 경험치는 180 EXP에서 멈추고 초과분은 버린다. 남은 경험치가 30 EXP보다 적으면 사용 전에 초과분이 적용되지 않는다는 안내를 표시한다.
- 성장 공개 대기 중에는 기존처럼 나이와 돌봄 상태가 멈춘다. 영양제로 빨리 성장 준비 상태에 도달해도 나이 자체는 변경하지 않는다.
- 성체 이후에는 경험치 누적을 중단한다. 3단계 성장과의 연계는 추후 확장 때 설계한다.
- 기존 저장 데이터 전환: 성장 준비 전 아기의 기존 나이를 활성 실행 분으로 변환하여 경험치로 설정한다 (기존 나이 초 / 60, 최대 180 EXP). 3시간 이상이면 성장 준비 대상으로 처리한다. 기존 성체와 성장 준비 개체는 상태와 확정된 성장 후보를 유지하고, 모든 개체의 나이는 변경하지 않는다.
- 현재 우선 개선안을 로컬 EXE에 구현했다. 디펜스는 개발 보류 상태로 유지한다.

## 쓰다듬기 실행 제한과 피로

- 상태: v0.1.14 로컬 구현 완료 (Git 반영: v0.1.14)
- 쓰다듬기는 활성 실행 시간 기준 3분에 한 번만 실행할 수 있다.
- 성공적으로 실행할 때 피로를 1 증가시킨다. 최대 피로는 기존과 같이 100이다.
- 기존 실행 보상인 교감 +1, 씨앗 +2는 유지하며 성공한 쓰다듬기마다 지급한다.
- 쿨타임 중에는 쓰다듬기 메뉴를 비활성화하고 남은 시간을 표시한다. 실행·보상·피로 증가를 모두 막는다.
- 비활성화와 프로그램 종료 등 시간 정지 규칙은 기존 육성 시스템을 따른다.
