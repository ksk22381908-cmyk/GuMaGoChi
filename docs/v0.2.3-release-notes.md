# GuMaGoChi v0.2.3 · 메뚜기 두 가지 행동 패턴

밭 달리기의 메뚜기가 항상 점프하던 동작을 두 가지 패턴으로 나눴습니다.

- 공통 말풍선 ‘뛸까말까~’ 뒤에 반반 확률로 행동을 선택합니다. 접근 도중 선택은 바뀌지 않습니다.
- ‘뛰어야지!’: 몸을 낮추고 다리를 접은 뒤 점프합니다. 플레이어는 지상으로 통과할 수 있습니다.
- ‘안뛸래~’: 점프하지 않고 지상으로 다가옵니다. 플레이어가 점프해서 피해야 합니다.
- 결정 말풍선은 준비 시간 후반부터 실제 행동 동안 유지되며, 모습과 충돌 판정도 선택한 행동을 따릅니다.

기존 집 UI 개선, 둥근 모서리 달리기, 두더지, 성체 31종과 저장 데이터는 유지합니다.

Windows 10/11 및 .NET Framework 4.8 이상에서 ZIP 전체를 압축 해제한 뒤 GuMaGoChi.exe를 실행하세요. assets 폴더를 함께 유지하고 업데이트 전에 실행 중인 프로그램을 종료하세요. 저장 위치는 %LOCALAPPDATA%\GuMaGoChi\save.json입니다.

검증: 모델 검사 12,191개, 기존 UI·캐릭터 프레임 744개 검사와 렌더링 검증 통과. 메뚜기의 말풍선 분기, 준비 동작, 실제 점프 여부와 두 패턴의 실제 이미지 회피·충돌을 검사했습니다.
