# GuMaGoChi v0.2.6

## 변경 사항
- 집 페이지 안내의 폭을 넓혀 '6마리' 등의 마릿수 표시가 잘리지 않도록 수정했습니다.
- 기존 저장 데이터가 있어도 EXE 실행 직후 고구마 집 창이 열립니다.

## 업데이트
v0.2.5 사용자는 트레이 우클릭 또는 집의 저장·사용 안내에서 업데이트 확인 → 다운로드 및 설치를 선택하세요.
다운로드·검증 후 저장하고 종료하며, 설치 후 다시 실행합니다. 육성 저장 데이터와 활성 상태는 유지합니다.
v0.2.4 이하 사용자는 ZIP 전체를 한 번 수동으로 압축 해제해야 합니다. EXE와 assets 폴더를 함께 유지하세요.

## 검증
모델 테스트 12,222개, UI 프레임 744개와 UI·디펜스 렌더링 검증을 통과했습니다.
50%·100%·200% 배율에서 마릿수 문장이 표시 영역에 맞고 버튼과 겹치지 않는 회귀 테스트를 추가했습니다.
