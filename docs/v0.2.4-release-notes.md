# GuMaGoChi v0.2.4

## 변경 사항
- 비상탈출: Space + E 동시 누르기 또는 고구마·트레이 우클릭 메뉴. 모든 창을 숨기고 상태를 저장한 뒤 종료하며, 활성·비활성 상태는 변경하지 않습니다.
- 배율 조정: 캐릭터와 UI를 10~200%, 10% 단위로 조정하고 저장합니다. 진행 중인 활동·달리기·디펜스 전투에서는 변경을 잠시 막습니다.
- 텍스트: 축소한 이미지의 글자가 뭉개지지 않도록 실제 화면 크기의 폰트로 직접 렌더링합니다.
- 디펜스: 메뚜기의 점프를 낮고 느리게 바꾸고, 착지 후 1.2초 멈췄다가 다시 이동합니다. 버러지와 분열 개체는 고구마 높이에 맞춰 아래쪽에서 출현합니다.
- 아이콘: EXE, 창 제목 표시줄, 작업표시줄에 고구마 아이콘을 적용합니다.

## 설치 및 저장
ZIP 전체를 압축 해제한 뒤 GuMaGoChi.exe를 실행하세요. assets 폴더를 함께 유지해야 합니다.
기존 저장 위치는 `%LOCALAPPDATA%\GuMaGoChi\save.json`으로 유지됩니다. 캐릭터 종류와 기존 육성 기록은 줄이거나 삭제하지 않습니다.
이전 버전의 비상탈출로 이미 비활성화된 개체는 한 번 다시 활성화해야 합니다.
Space + E는 다른 프로그램에서도 작동하므로 동시에 누를 때 주의하세요.

모델 테스트 12,197개, UI 프레임 744개, UI·디펜스 렌더링 검증 통과.
