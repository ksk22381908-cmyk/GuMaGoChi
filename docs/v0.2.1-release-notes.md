# GuMaGoChi v0.2.1

- 2차 진화 시범 디자인 8종과 행동 프레임을 추가했습니다. 우클릭의 2차 진화 모습 선택에서 변경할 수 있습니다.
- 모니터 네 면을 따라 이동하며 장애물을 피하는 고구마 밭 달리기와 최고 기록, 공유 이미지 저장을 추가했습니다.
- 점심 메뉴 곡선 사다리와 사용자 메뉴 편집을 추가했습니다.
- 아기와 성체 31종의 상황별 대사를 확장하고 반복 표시를 줄였습니다.

Windows 10/11 및 .NET Framework 4.8 이상에서 ZIP 전체를 압축 해제한 뒤 GuMaGoChi.exe를 실행하세요. assets 폴더를 함께 유지해야 합니다. 업데이트 전에 실행 중인 프로그램을 종료하세요.

기존 육성 데이터는 %LOCALAPPDATA%\GuMaGoChi\save.json에서 유지됩니다.

검증: 모델 검사 10,766개, UI 및 캐릭터 프레임 744개 검사와 렌더링 검사.
