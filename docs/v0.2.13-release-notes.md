# GuMaGoChi v0.2.13

- 왕구마를 확정 A안의 금왕관·붉은 망토·보석 왕홀 디자인으로 교체하고 6종 동작 24프레임을 적용했습니다.
- 왕구마의 2차 진화 선택에 **왕고구마**와 **망했구마**를 추가했습니다. 각 진화체에 6종 동작 24프레임을 적용하며 기존 나이·돌봄 기록·저장을 유지합니다.
- 왕고구마: 근육질 왕. 공격력 48, 공격 간격 2.6초, 짧은 사거리 280. 왕홀을 휘두르면 0.5초 뒤 타겟 지역에 반경 55의 작은 충격파가 발생합니다.
- 왕고구마의 **왕의 충격파**: 반경 180에 공격력 3배 피해와 2초 기절, 재사용 30초.
- 망했구마: 깨진 왕관과 누더기를 걸친 거지왕. 공격력 12, 기본 간격 0.65초, 쓰레기 직선 투척. 같은 대상 연속 공격마다 속도 +10%, 최대 2배. 대상 변경·처치 시 초기화합니다.
- 망했구마의 **바가지 깨기**: 동냥 바가지를 떨어뜨려 반경 180에 공격력 2.5배 피해와 2초 기절, 재사용 28초.
- 사거리·효과 반경은 기존 전투 좌표 배율을 적용합니다. 거대 적은 기존 규칙대로 기절 시간이 절반이며 기절 면역은 유지합니다. 다른 캐릭터의 사거리와 기존 전투 수치는 변경하지 않습니다.

## 다운로드 및 실행

이번 버전은 사용자 요청에 따라 **미서명 배포**입니다. SmartScreen 경고가 표시될 수 있으며 게시자 서명이 적용된 파일로 안내하지 않습니다.

Windows ZIP을 새 폴더에 전체 압축 해제한 뒤 `GuMaGoChi.exe`를 실행하세요. `assets`와 `.config`는 함께 유지해야 합니다. Windows 10/11과 .NET Framework 4.8 이상이 필요합니다. 기존 육성 저장은 `%LOCALAPPDATA%\GuMaGoChi`에서 이어서 사용합니다.
