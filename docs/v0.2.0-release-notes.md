# GuMaGoChi v0.2.0 · 고구마 버러지 디펜스

바탕화면에서 플레이하는 무한 라운드 디펜스를 추가했습니다.

- 보유 고구마를 우측 하단의 수직 1~5번 칸에 드래그하여 편성합니다. 아기도 참가할 수 있습니다.
- 캐릭터별 자동 기본 공격과 클릭 고유 스킬, 우클릭 능력치·특성·스킬 확인을 지원합니다.
- Shift + 왼쪽 클릭으로 공격 표식을 설정하고 다시 클릭하면 해제합니다. 사거리 제한은 없습니다.
- 라운드 완료마다 무작위 강화 카드 3장 중 1장을 골라 개별 또는 전체 고구마를 강화합니다. 초기 공격력·공격속도는 낮추고 강화는 이번 전투에서만 유지합니다.
- 31종 기본 공격·스킬과 6종 버러지 이동 프레임을 적용했습니다. 시작 이미지는 3초 표시 후 페이드 아웃하며 클릭으로 바로 스킵합니다.
- 최고 기록과 10마리 처치당 씨앗 1개를 저장합니다. 전투 중에는 육성 시간이 멈춥니다.
- 화면 크기에 맞게 충돌 판정을 줄였고 HD·4K에서도 동일한 실제 픽셀 범위로 판정합니다. 상단 정보와 종료 버튼은 겹치거나 잘리지 않도록 조정했습니다.

**설치:** `GuMaGoChi-0.2.0-windows.zip` 전체를 압축 해제하고 `GuMaGoChi.exe`를 실행하세요. 디자인 애셋이 포함되어 있으므로 assets 폴더를 함께 유지해야 합니다. Git으로 업데이트할 때도 프로그램을 종료한 뒤 받아 주세요.

기존 육성 데이터는 `%LOCALAPPDATA%\GuMaGoChi\save.json`에서 그대로 읽습니다. 새 전투의 카드 강화는 초기화되며 기존 개체의 육성 능력치를 변경하지 않습니다.

검증: 749개 모델 검사, 기존 UI·744개 캐릭터 프레임 검사, 카드·편성·시작화면 스킵·능력치 창 렌더링, HD·4K 충돌 적중/빗나감 검사.
