# 점심 뭐 먹지? · 곡선 사다리

고구마를 우클릭하고 **점심 뭐 먹지? · 곡선 사다리**를 선택합니다. 깨어 있는 활성 고구마로 실행하며 놀이·훈련·달리기·디펜스 중에는 새 창을 열 수 없습니다.

- 메뉴 다시 뽑기: 편의점 털기를 포함한 41개 메뉴에서 중복 없이 5개를 추첨합니다. 횟수 제한이 없습니다.
- 같은 메뉴로 다시 타기: 5개 메뉴는 유지하고 곡선과 연결점만 새로 만듭니다.
- 1~5번 출발: 고구마가 곡선을 따라 내려가며 연결점에서 옆줄로 이동합니다. 지나온 길을 주황색으로 표시합니다.
- 결과 이미지 저장: 도착 후 화면을 PNG로 저장합니다.
- 메뉴 목록 편집: 한 줄당 메뉴 하나씩 입력하거나 붙여 넣고 저장합니다. 기본 41개를 편집해도 되고 목록 전체를 회사 주변 식당 메뉴로 교체해도 됩니다. 빈 줄·중복은 자동 제외하며, 메뉴는 5~200개·항목당 40자까지입니다. 식당 이름을 함께 적어도 됩니다.
- 기본 41개로 되돌리기: 편집창에서 이 버튼을 누른 뒤 저장하면 사용자 목록 대신 기본 후보를 다시 사용합니다.

메뉴 5개는 항상 공개합니다. 추첨에는 씨앗 소모·보상·쿨타임이 없습니다. 이동 중에는 메뉴 변경과 출발 버튼이 잠겨 결과가 바뀌지 않습니다. 도착 후 다른 출발점으로도 같은 사다리를 탈 수 있습니다. 갈아타는 연결에는 작은 매듭이 있으며, 각 출발점은 서로 다른 메뉴 하나에 연결됩니다.

전체 게임 일시정지 중에는 이동도 멈춥니다. 창을 닫으면 언제든 종료할 수 있으며 육성 기록과 재화는 변경하지 않습니다. 추첨된 5개 메뉴와 사다리는 이번 창에서만 유지하고 다음 실행 때 새로 추첨합니다. 사용자 메뉴 목록은 save.json에 저장하여 다음 실행에도 유지합니다.
