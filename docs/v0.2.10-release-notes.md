# GuMaGoChi v0.2.10

- 성체 목록을 22종으로 정리했습니다. 삭제된 캐릭터 번호는 유지하며 기존 저장 데이터의 캐릭터·성장 후보·도감 기록을 지정된 캐릭터로 치환합니다.
- 아기고구마를 꼬마 새싹 디자인으로 변경하고 6종 동작을 적용했습니다. 먹기 모션의 중복 팔을 제거했습니다.
- 딸기마를 베리마로 변경하고 딸기 케이프 디자인을 적용했습니다.
- 베리마의 2차 진화 선택에 블루베리마와 라즈베리마를 추가했습니다. 나이와 돌봄 기록은 유지됩니다.
- 블루베리마는 몸통 중심을 기준으로 구르며 이동하고, 블루베리 투척 후 3초간 독 피해를 줍니다.
- 라즈베리마는 1초 동안 과즙 빔으로 지속 공격합니다. 두 진화체의 먹기 모션에서 중복 팔을 제거했습니다.
- 당근마에 당근 후드와 멜빵옷 디자인을 적용하고 대기·이동·먹기·공격·수면·땅 파기 24프레임을 교체했습니다.
- 전투 범위 표시와 착탄·지속 효과 범위 판정을 개선했습니다.

기존 프로그램의 업데이트 기능을 사용하거나 전체 Windows ZIP을 내려받아 실행할 수 있습니다. v0.2.9 이용자를 위한 차등 업데이트를 제공합니다. 저장 데이터는 설치 폴더와 별도로 보관됩니다.
