# 고구마 버러지 디펜스 기획안

상태: 기획안 보관, 개발 보류. 우선 육성 개선안만 검토한다. 디펜스 구현과 Git 업로드는 각각 별도 요청 때 진행한다.

시작 화면 디자인: [고구마버러지디펜스Intro.png](../assets/higgsfield/defense/고구마버러지디펜스Intro.png)

## 사용자 확정 요구

1. 왼쪽에서 애벌레가 기어나온다.
2. 오른쪽에서 사용자가 키운 고구마를 최대 5개체까지 배치하여 방어한다.
3. 각 고구마는 기본 공격을 자동으로 수행한다.
4. Shift + 마우스 왼쪽 클릭으로 고구마들의 공통 공격 지점을 지정한다.
5. 벌레 10마리당 씨앗 1개를 지급한다.
6. 고구마 종류별로 개별 공격 특성과 스킬을 부여한다.

## 추가 합의 사항

- 입장 전에 보유 고구마 중 최대 5마리를 직접 편성한다.
- Shift + 왼쪽 클릭으로 공통 집중 공격 지점을 지정한다.
- 처치한 벌레 10마리마다 씨앗 1개를 지급한다.
- 오른쪽 땅속 집 입구를 방어한다. 통과한 벌레가 방어 게이지를 감소시킨다.
- 방어 게이지가 소진되면 해당 판이 종료된다. 디펜스 패배로 육성 개체가 사망하지 않는다.
- 아래 여섯 캐릭터의 공격·스킬 방향을 채택한다. 구체적인 수치와 나머지 캐릭터 설계는 후속 기획으로 정한다.
- 기본 공격은 자동으로 수행하고, 스킬은 사용자가 해당 고구마를 왼쪽 클릭하면 발동한다. 자동으로 스킬을 사용하지 않는다.
- Shift + 왼쪽 클릭은 공통 공격 지점 지정으로 처리하며, 고구마 위를 클릭하더라도 스킬 발동과 중복 처리하지 않는다.

## 세부 검토안 (미확정)

- 입장 전에 보유 개체 중 최대 5마리를 직접 선택한다.
- 별도의 디펜스 화면 안에서 입력을 처리한다. 다른 프로그램에서 하는 Shift + 클릭은 게임 명령으로 받지 않는다.
- 일반 상태에서는 각 고구마가 사거리 안의 적을 자동으로 공격한다.
- Shift + 클릭한 지점에 표식을 표시하고, 그 주변 적을 우선 공격한다. 사거리 밖이면 위치는 유지하며 공격하지 않는다.
- 표식 해제 버튼으로 일반 자동 공격으로 돌아간다.
- 씨앗은 생성된 벌레가 아닌 처치한 벌레 10마리마다 1개 지급한다. 10마리 미만의 누적 처치 수는 다음 판에도 이어간다.
- 스킬별 재사용 시간을 두고, 사용 가능 여부와 남은 대기 시간을 고구마 주변에 표시하는 방향을 제안한다.
- 기존 다섯 특기(힘·정밀·민첩·집중·친화)를 전투 역할의 기준으로 쓰되, 종류별 공격 효과와 스킬은 개별 설계한다.

## 채택한 개별 공격·스킬 방향

| 캐릭터 | 기본 공격 특성 | 스킬 초안 |
|---|---|---|
| 당근마 | 느리지만 강한 직선 투사체 | 연속 투척으로 집중 화력 |
| 냥고마 | 빠르고 정확한 단일 공격 | 약점을 노리는 강력한 한 발 |
| 개굴마 | 튕겨 다음 적까지 맞히는 공격 | 점액으로 적 이동 감속 |
| 마법마 | 좁은 범위에 피해를 주는 마법탄 | 지정 지점에 넓은 범위 공격 |
| 햇살이 | 보통 속도의 기본 공격 | 주변 아군 공격 속도 증가 |
| 간첩마 | 고구마인 척 감자탄을 발사 | 위장 감자 폭탄으로 범위 피해 |

## 다음 설계 제안 (미확정)

- 첫 구성은 5웨이브로 하고, 각 웨이브에 벌레 10마리를 배치한다. 전부 처치하면 기본 보상 합계는 씨앗 5개다.
- 웨이브마다 출현 간격과 벌레 체력을 조절하여 난이도를 높인다. 적 종류는 우선 기본 애벌레 한 종류로 시작한다.
- 스킬은 해당 고구마 클릭으로 발동한다. 공격 스킬은 현재 공격 지점 지정 규칙을 따르고, 지원 스킬은 범위 내 아군에게 적용하는 방향을 제안한다.
- 처치 보상은 10마리째 처치할 때 즉시 지급한다. 패배하거나 중단해도 받은 씨앗은 유지한다.
- 추가 클리어 보상, 기본 공격 속도, 스킬 재사용 시간과 방어 게이지 수치는 밸런스 기획 때 정한다.

## 다음 결정 사항

- 공격 지점 지정이 전원 공통인지, 추후 개별 지정도 허용할지.
- 스킬별 재사용 시간, 대상이 없을 때의 처리와 사용 가능 표시.
- 아기 참여 가능 여부와 같은 종류 중복 편성 가능 여부.
- 나머지 캐릭터별 공격·스킬, 수치, 웨이브 길이 및 난이도.
- 디펜스 중 육성 시간·피로 처리와 중단 시 보상 저장 규칙.
