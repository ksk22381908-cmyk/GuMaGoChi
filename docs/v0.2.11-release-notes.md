# GuMaGoChi v0.2.11

- 당근마에 새싹·주황 멜빵바지 디자인과 6종 동작 24프레임을 적용했습니다.
- 당근마의 2차 진화 선택에 농부마와 황달마를 추가했습니다. 기존 나이·돌봄 기록·전투 수치는 유지합니다.
- 농부마는 밀짚모자와 바구니를 사용하며 바구니에서 당근을 꺼내 던집니다.
- 황달마는 얼굴만 노르스름한 통통한 고구마이며 먹던 당근 조각을 입으로 뱉습니다.
- 디펜스 일반 공격·5연속 스킬과 공 놀이·훈련에 각 진화의 당근 투사체를 표시합니다.
- 시트 행 경계에서 새싹이 잘리지 않도록 프레임 분리를 개선했습니다.

## Windows에서 실행

`GuMaGoChi-0.2.11-windows.zip`을 다운로드하고 **전체 압축 해제**한 뒤 폴더 안의 `GuMaGoChi.exe`를 실행하세요. `assets`와 `GuMaGoChi.exe.config`를 EXE와 함께 유지하세요. Windows 10/11과 .NET Framework 4.8 이상이 필요하며 별도의 개발 도구는 필요 없습니다.

기존 프로그램을 종료한 뒤 새 폴더에서 실행하세요. 육성 데이터는 `%LOCALAPPDATA%\GuMaGoChi\save.json`에 있어 기존 기록을 이어서 사용합니다. 새 PC로 옮길 때는 이전 PC의 저장 데이터 백업을 복원해야 합니다.

SHA-256 확인: `Get-FileHash .\GuMaGoChi-0.2.11-windows.zip -Algorithm SHA256`의 결과를 함께 배포한 `.sha256` 파일과 비교하세요.
