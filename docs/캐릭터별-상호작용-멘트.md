# 캐릭터별 상호작용 멘트

아기고구마 1종 + 진화체 31종. 기존 멘트에 상황별 3개를 추가했습니다. 각 개체·상황별로 4개를 무작위 순서로 한 번씩 표시하며 묶음 경계에서도 직전 멘트를 반복하지 않습니다. 새 멘트는 총 1,248개(32종 × 13상황 × 3개)이며, 상태 요청은 치료·물·휴식별로 같은 캐릭터의 요청 문형을 사용합니다. 대사 순서는 저장하지 않으며 프로그램을 다시 실행하면 새로 섞습니다.

상태 요청 우선순위는 병세 > 20 → 치료, 배고픔 > 60 → 물, 피로 > 75 → 휴식입니다. 아기의 실제 자동 혼잣말은 기존 돌봄 기록 기반 힌트와 새 멘트 3개를 함께 사용합니다. 아래 혼잣말의 기존 멘트는 Dialogue.Get(3)의 기본값입니다.
