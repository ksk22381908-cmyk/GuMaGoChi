# GuMaGoChi v0.2.7

## 변경 파일 업데이트
변경되지 않은 파일의 크기와 SHA-256을 로컬에서 확인합니다. 기준 파일이 모두 맞으면 EXE와 변경된 에셋만 들어 있는 작은 ZIP을 다운로드합니다.
파일이 누락·변경되었거나 릴리즈에 패치가 없으면 전체 ZIP을 받습니다. 패치 자체의 체크섬과 실행 파일 버전도 확인합니다.
교체 파일만 백업·설치하고 실패 시 복구합니다. 저장 데이터와 변경되지 않은 에셋은 교체하지 않습니다.
기존 v0.2.6 이하의 업데이트 프로그램은 이 기능을 처음 받는 한 번은 전체 ZIP을 다운로드합니다. 이후부터 패치가 지원됩니다.
직전 패키지 기준의 파일 단위 패치이며, 여러 버전의 변경을 합성하거나 파일 내부의 바이너리 차이를 적용하는 방식은 아닙니다. 불필요해진 옛 에셋은 자동 삭제하지 않습니다.

## 배포 방법
`package.ps1 -PreviousPackagePath <이전 배포 폴더>`로 이전 버전과 비교합니다. 현재 기본 기준은 release/GuMaGoChi-0.2.6-windows입니다.
전체 windows.zip과 .sha256, delta.zip과 .sha256, delta.json을 같은 GitHub 릴리즈에 모두 업로드합니다. 목록·패치는 검증된 정식 저장소의 릴리즈 URL만 허용합니다.
이전 패키지가 없으면 전체 ZIP만 생성합니다.

## 검증
모델 테스트 12,230개, UI 프레임 744개와 UI·디펜스 렌더링 검증 통과.
정상·누락·동일 크기 변조 파일, 잘못된 경로, 저장 파일 대상 거부, EXE 단독 패치 설치와 기존 파일 보존을 검증했습니다.
