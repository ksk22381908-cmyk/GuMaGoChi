# 2차 진화 디자인 시범 적용

| 기존 캐릭터 | 모습 A | 모습 B |
| --- | --- | --- |
| 간첩마 | 짭구마 | 찐감자 |
| 냥고마 | 호랑고마 | 골골마 |
| 멍고마 | 맹견마 | 치와마 |
| 해적마 | 해적선장마 | 유령해적마 |

살아 있고 깨어 있는 활성 개체를 우클릭하여 **2차 진화 모습 선택**을 엽니다. 놀이·훈련·디펜스 중에는 선택할 수 없습니다. **1차 모습으로 돌아가기**로 되돌릴 수 있습니다.

각 캐릭터에 대기·이동·먹기·공 던지기·수면·땅속 들어가기 4프레임씩, 8종 총 192프레임을 적용했습니다. 치와마는 최종 승인된 보라색 고구마 몸과 노란 주둥이 디자인을 사용합니다. 바탕화면·집·도감·앨범·디펜스에 선택한 모습을 표시하며 발견한 모습은 도감에 남습니다.

현재 시범 적용은 외형과 캐릭터 이름·성격 표시를 바꿉니다. 성장 조건과 전용 능력은 미정이므로 기존 캐릭터의 능력·상호작용 대사를 사용합니다. 개체 이름·나이·성장 경험치·돌봄 기록·씨앗은 그대로 유지합니다. 기존 1차 캐릭터 삭제·이름 변경 기획은 이번 적용에 포함하지 않았습니다.

저장 형식은 Version 3이며 기존 Version 1·2를 읽을 수 있습니다. 새 저장을 사용하려면 업데이트한 EXE가 필요합니다. EXE 옆의 assets 폴더를 함께 유지하세요.

원본 시트는 assets/higgsfield/evolutions에 보관합니다. 실행 시 흰 외부 배경을 제거하고 실제 행의 빈 구간을 기준으로 프레임을 분리해 동일 배율로 렌더링합니다. 치와마 공 던지기 첫 컷의 소품 오류는 두 번째 컷 재사용으로 보정했습니다. 생성 이미지 특성상 프레임마다 무늬·윤곽에 작은 차이가 남습니다.
