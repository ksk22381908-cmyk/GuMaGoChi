# 고구마 버러지 디펜스 · 사용 안내

땅속 집 → **버러지 디펜스** → **디펜스 시작 · 편성하기**를 선택한다. 보유 고구마 목록에서 오른쪽 아래의 1~5번 칸으로 원하는 고구마를 드래그한다. 이미 편성한 고구마를 다른 칸으로 드래그하면 서로 교환한다. × 버튼으로 비울 수 있다. 빈칸은 유지하며 한 개체를 여러 칸에 중복 배치할 수 없다. 아기·비활성 개체도 참가 가능하며 죽은 개체는 제외한다.

**전투 시작**을 누르면 현재 모니터의 바탕화면 위에서 실행한다. 시작 이미지를 전체 화면에 비율을 유지해 3초간 표시한 뒤 0.7초 동안 페이드 아웃한다. 이미지를 클릭하면 바로 스킵하고 전투를 시작한다. 전투 중에는 편성을 고정한다. 고구마들은 화면 오른쪽 아래의 좁은 수직 5칸에 배치된다. 오른쪽 집 이미지는 표시하지 않는다.

- 기본 공격은 자동이다. 캐릭터별 직선·포물선·지점 공격 이펙트를 사용한다.
- **Shift + 왼쪽 클릭**: 표식이 없으면 클릭한 지점에 표식을 만든다. 표식이 있는 상태에서 다시 Shift + 클릭하면 위치와 관계없이 해제하고 자동 조준으로 돌아간다. 표식에 적이 없어도 공격한다. 사거리 제한은 없다.
- **고구마 왼쪽 클릭**: 고유 스킬을 사용하고 캐릭터별 멘트를 말풍선으로 표시한다. 당근마는 한 개씩 다섯 번 빠르게 발사한다.
- **고구마 우클릭**: 현재 전투 능력치, 성격, 고유 특성, 스킬 효과·쿨타임, 이번 판 강화 배율을 확인한다.
- 디펜스 일시정지 버튼과 ESC 일시정지 기능은 제공하지 않는다. **이번 판 종료**로 종료하고 다시 편성할 수 있다.

## 라운드와 강화 카드

최고 기록을 겨루는 무한 라운드다. 방어선 체력 100으로 시작한다. 적이 오른쪽에 도달하면 체력이 감소하고 0이면 종료한다. 5라운드마다 거대 버러지가 등장한다. 모든 적과 분열된 꼬마까지 처리하면 라운드가 완료된다. 체력이 5 회복되고, 무작위 카드 3장 중 1장을 선택한다. 선택 후 3초 뒤 다음 라운드를 시작한다. 선택하는 동안 전투·쿨타임은 진행되지 않는다.

초기 공격력은 이전 수치의 약 65%(정수 반올림), 기본 공격 간격은 1.35배다. 아기는 공격력 6, 기본 간격 1.35초로 시작한다. 강화를 모아 해당 전투에서 성장한다.

| 강화 | 지정 고구마 1마리 | 전체 고구마 |
|---|---|---|
| 기본 공격·스킬 피해 | +30% | +12% |
| 공격속도 | +25% | +10% |
| 스킬 피해 | +35% | +15% |
| 스킬 쿨타임 | -20% | -10% |

개인 카드는 대상 칸·이름을 표시한다. 공격 스킬이 없는 개체는 개인 스킬 피해 카드 대상으로 선택하지 않는다. 공격 스킬을 가진 개체가 없는 편성에는 전체 스킬 피해 카드도 나오지 않는다. 카드 강화는 배율로 누적하며 공격속도는 초기의 최대 4배, 쿨타임은 최소 5초다. 새 전투에서는 모든 강화가 초기화된다. 육성 데이터의 능력치는 바꾸지 않는다.

## 적·보상·기록

초록 애벌레, 점프하는 메뚜기, 껍질형 딱정벌레, 분열하는 송충이, 꼬마 진딧물, 손으로 헤치는 두더지가 등장한다. 분열형 처치 시 꼬마 세 마리가 생기며 각각 처치 수에 포함된다.

처치 10마리마다 씨앗 1개를 즉시 지급한다. 종료해도 지급된 씨앗은 유지하고, 10마리 미만의 나머지 처치 수는 다음 전투로 이월하지 않는다. 최고 기록은 완료 라운드를 우선하고 같으면 처치 수로 비교한다. 기록과 씨앗은 기존 save.json에 저장한다. 온라인 순위표는 없으며 화면 캡처로 비교할 수 있다.

전투 중에는 육성 시간·상태 변화가 멈추고, 전투 결과로 고구마가 죽거나 육성 상태가 손상되지 않는다. 상단 정보는 고정 크기의 작은 영역에 표시한다. 캐릭터·이펙트는 해상도에 따라 확대하지 않으며 넓은 화면에서도 적의 통과 시간은 유지된다.

EXE와 assets 폴더를 함께 유지해야 한다. 31종 공격·스킬, 6종 적 이동 프레임은 assets/higgsfield/defense에서 읽고 고구마 공격 동작은 기존 공 던지기 모션을 사용한다.
충돌 판정도 표시 크기에 맞춘다. 적·투사체와 착지/스킬 범위는 축소된 실제 화면 픽셀을 기준으로 비교하므로 HD와 4K에서 동일하게 적용된다. 직선 투사체는 이동 경로의 충돌을 검사하고 포물선은 착지 지점에서 범위 피해를 검사한다. 종료 버튼은 전체 문구를 표시할 수 있도록 최소 너비와 자동 크기를 적용한다.
