# GuMaGoChi v0.2.9

## 변경 사항
- 1차 진화 시 두 후보의 모습·이름·성격·특기를 보고 하나를 선택합니다.
- 후보는 기존 돌봄·놀이·훈련 가중치로 추첨하며 서로 중복되지 않습니다.
- 선택을 미루거나 게임을 재시작해도 후보가 유지됩니다. 기존 성장 대기 고구마의 원래 후보는 유지하고 두 번째 후보를 추가합니다.
- 선택한 모습만 도감·성장 기록에 등록하고 진화 보상은 한 번 지급합니다.
- Space + E를 동시에 0.5초 이상 눌러야 비상탈출합니다. 하나라도 떼면 시간이 초기화됩니다. 메뉴 비상탈출은 즉시 작동합니다.

## 업데이트
게임의 트레이 또는 집의 저장·사용 안내에서 업데이트 확인 → 다운로드 및 설치를 선택하세요.
v0.2.8 배포 파일과 일치하면 변경 파일 패치를 받습니다. 기준 파일이 다르면 전체 ZIP으로 업데이트합니다.
기존 육성 저장 데이터와 활성 상태는 유지됩니다. 자동 업데이트가 없는 구버전은 전체 ZIP을 받아 압축 해제한 뒤 실행하세요.
