# GuMaGoChi v0.2.5

## 변경 사항
- 게임 내 업데이트: 트레이 우클릭 또는 집의 저장·사용 안내에서 업데이트 확인을 선택합니다.
- 새 버전을 확인한 뒤 다운로드 및 설치를 누르면 SHA-256과 ZIP 경로·실행 파일 버전을 검증하고, 게임을 저장·종료한 뒤 별도 업데이터가 설치하고 재실행합니다.
- 설치 전 기존 실행 파일과 에셋을 백업하고, 교체 실패 시 복구합니다. 육성 저장 데이터와 캐릭터 활성 상태는 유지합니다.
- 달리기 좌표·점프·장애물 이동을 동일한 논리 배율로 맞춰 200%에서도 애벌레를 점프로 넘을 수 있도록 수정했습니다. 모서리 연결도 같은 배율을 사용합니다.

## 설치 및 업데이트
v0.2.4 이하 사용자는 이 ZIP 전체를 한 번 수동으로 압축 해제해야 합니다. 이후 버전은 게임 안에서 업데이트할 수 있습니다.
GuMaGoChi.exe와 assets 폴더를 함께 유지하고, 쓰기 가능한 폴더에서 실행하세요.
저장 위치는 `%LOCALAPPDATA%\GuMaGoChi\save.json` 그대로입니다. 설치 백업은 `%LOCALAPPDATA%\GuMaGoChi-Updater` 아래에 보관됩니다.
다운로드·검증 실패 시 게임은 종료하지 않습니다. 설치 중 게임 종료를 기다리며 강제 종료하지 않습니다.

## 검증
모델 테스트 12,222개와 UI 프레임 744개, UI·디펜스 렌더링 검증을 통과했습니다. 별도 테스트 설치 폴더에서 부모 프로세스 종료 대기·설치·백업·재실행을 검증했습니다.
업데이트 메타데이터·경로 검증, 체크섬 오류, 저장 보존, 설치 실패 후 복구, 버튼 배율 테스트를 포함합니다.
달리기 10~200%의 점프·비점프 충돌과 네 면·모서리 이동을 검증합니다.
