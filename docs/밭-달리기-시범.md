# 고구마 밭 달리기 시범

깨어 있는 활성 고구마를 우클릭하고 **고구마 밭 달리기**를 선택합니다. 공놀이·훈련·디펜스와 동시에 실행할 수 없습니다.

시작한 고구마가 있는 모니터의 전체 화면 네 면을 아래→오른쪽→위→왼쪽 순서로 달립니다. 바깥 여백 없이 화면 끝을 사용하며 아래쪽은 작업 표시줄 위에 겹쳐 표시됩니다. 모서리는 둥근 경로를 따라 서서히 회전합니다. 화면 중앙은 투명하며 바탕화면이 보입니다.

- 스페이스 또는 달리는 캐릭터 클릭: 화면 안쪽으로 점프
- 시작·재도전은 2초 준비 후 출발합니다. 다른 창으로 전환 또는 게임 일시정지 시 멈추며, 복귀하면 1초 준비 후 이어집니다.
- Esc 또는 끝내기: 보상 없이 중단
- 충돌 후 다시 달리기: 새 도전
- 기록 이미지 저장: 캐릭터·이번 점수·개인 최고 기록을 PNG로 저장

거리에 따라 점수가 증가하고 속도도 상승합니다. 버러지는 모서리도 연속으로 통과합니다. 충돌은 고구마의 건강에 영향을 주지 않습니다. 기록은 캐릭터 공통 개인 최고이며 온라인 순위표는 없습니다.

충돌로 완주하면 100점당 씨앗 1개, 한 판 최대 6개·하루 최대 20개를 지급합니다. 날짜는 컴퓨터의 현지 날짜를 사용합니다. 종료·취소한 도전에는 보상을 지급하지 않습니다. 최고 기록과 지급 한도는 저장 파일에 보관하며 기존 저장에도 기본값으로 추가됩니다.

모서리는 실제 호 길이에 맞춰 이동하므로 지상 이동 속도가 일정하며, 점프 중에도 같은 둥근 경로를 따라 회전합니다. 착지 직전 0.12초 이내에 누른 점프는 착지 후 실행합니다.

장애물은 기존 디펜스 이미지를 활용한 3종입니다.

- 버러지: 처음부터 등장하며 고구마 반대 방향으로 이동합니다.
- 메뚜기: 120점부터 새로 배치되는 장애물에 섞입니다. 몸을 낮추고 다리를 접는 예고 후 화면 안쪽으로 점프합니다. 높이 떠 있을 때는 지상으로 지나갈 수 있습니다.
- 두더지: 300점부터 새 배치의 약 10% 비율로 선택됩니다. 움직이지 않는 흙더미가 흔들리고 흙가루가 나온 뒤 솟아오르며, 잠시 후 다시 숨습니다. 예고 중인 흙더미는 충돌하지 않습니다.

예고는 1.15초부터 난이도에 따라 줄지만 최소 0.85초를 유지합니다. 지나간 장애물은 플레이어 앞쪽으로 다시 배치하며, 다른 장애물과 충분한 간격을 확보하지 못하면 등장을 미룹니다. 기존 최고 기록과 보상 한도는 유지합니다.

충돌은 실제 표시 크기·회전의 불투명 픽셀로 검사합니다. 모서리에서도 별도의 축소 판정을 사용하지 않습니다. 일시정지·충돌 종료 시 장애물과 예고 동작도 멈춥니다. 모니터 해상도나 배율을 변경한 경우 활동을 종료하고 다시 시작하세요.
