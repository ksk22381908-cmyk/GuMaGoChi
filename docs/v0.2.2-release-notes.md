# GuMaGoChi v0.2.2 · 집 UI와 밭 달리기 개선

## 집과 팝업

- 상단 탭에 여백, 구분선과 선택 표시를 추가했습니다.
- 집의 활성 거주 고구마를 3열 × 2행, 페이지당 최대 6마리로 표시합니다. 목록에서 선택하면 해당 페이지를 열고, 새로고침 때는 현재 페이지를 유지합니다.
- 캐릭터 정보는 항목별 표로 표시하고 작은 창에서는 스크롤할 수 있습니다.
- 바탕화면과 집에서 공유하는 우클릭 메뉴를 돌봄, 성장, 놀이·훈련, 생활·관리로 구분했습니다. 비용과 부가 정보는 오른쪽에 표시하고 맛탕 만들기는 아래에 분리했습니다.
- 입양·이름 변경과 점심 메뉴 편집 팝업의 버튼에 자동 크기와 여백을 적용했습니다.

## 밭 달리기

- 호 길이 기준의 둥근 모서리 경로와 연속 회전을 적용했습니다. 점프 중 강제 위치 보정을 제거했습니다.
- 버러지에 더해 120점부터 메뚜기를 추가합니다. 몸을 낮추는 예고 후 화면 안쪽으로 점프하며, 높이 떠 있을 때 지상으로 통과할 수 있습니다.
- 300점부터 새 장애물 배치의 약 10% 비율로 두더지를 추가합니다. 흙더미가 흔들리고 흙가루가 나온 뒤 솟아오르며 다시 숨습니다. 예고 중에는 충돌하지 않습니다.
- 난이도가 올라가도 예고는 최소 0.85초를 유지합니다. 재배치할 때 플레이어 앞쪽의 여유 거리와 장애물 간격을 확인합니다.
- 시작·재도전에 2초, 일시정지 복귀에 1초 준비 시간을 추가했습니다. 착지 직전 0.12초의 점프 입력을 기억합니다.
- 실제 표시 모습과 동일한 충돌 판정을 사용하고 충돌 이미지 버퍼를 재사용합니다. 다음 씨앗까지의 점수와 오늘 남은 보상을 표시합니다.

## 설치와 검증

Windows 10/11 및 .NET Framework 4.8 이상에서 GuMaGoChi-0.2.2-windows.zip 전체를 압축 해제하고 GuMaGoChi.exe를 실행하세요. assets 폴더를 함께 유지하고 업데이트 전에 프로그램을 종료하세요.

기존 성체 31종, 육성 기록, 달리기 최고 기록과 보상 한도는 유지합니다. 저장 위치는 %LOCALAPPDATA%\GuMaGoChi\save.json입니다.

모델 검사 12,181개, 기존 UI와 캐릭터 프레임 744개 검사, 렌더링 검증이 통과했습니다. 추가로 6마리 페이지 이동, 100%·125%·150%·200% 크기 확대에서 팝업 버튼 배치, 모서리 이동 연속성, 예고 동작과 실제 이미지 충돌을 검사했습니다.
