# GuMaGoChi

윈도우 바탕화면에서 키우는 고구마 다마고치. **0.2.2: 집 UI · 달리기 개선 버전**입니다.

v0.2.2에서는 집 탭 구분, 한 화면 6마리 페이지 이동, 캐릭터 정보표, 공통 우클릭 메뉴와 팝업 버튼을 개선했습니다. 밭 달리기는 모서리 이동과 점프를 부드럽게 연결하고, 120점부터 예고 후 점프하는 메뚜기, 300점부터 흙더미 예고 후 솟는 두더지를 추가했습니다. 기존 성체 31종과 육성 저장 데이터는 유지합니다. [릴리즈 안내](docs/v0.2.2-release-notes.md)를 참고하세요.

고구마 우클릭에서 **고구마 밭 달리기**와 **점심 뭐 먹지? · 곡선 사다리**를 실행할 수 있습니다. 달리기는 모니터 네 면을 따라 점프하며 이동 버러지를 피하고 최고 기록·공유 이미지를 저장합니다. 점심 사다리는 기본 41개 또는 저장한 사용자 메뉴 목록에서 5개를 공개 추첨합니다. [달리기 안내](docs/밭-달리기-시범.md), [점심 사다리 안내](docs/점심-사다리-사용안내.md)를 참고하세요.

2차 진화 시범 디자인 8종의 대기·이동·먹기·공 던지기·수면·땅속 들어가기 프레임을 적용했습니다. 간첩마·냥고마·멍고마·해적마를 우클릭하고 **2차 진화 모습 선택**에서 변경합니다. 현재는 자유롭게 되돌릴 수 있는 모습 선택이며 기존 능력·나이·돌봄 기록을 유지합니다. [시범 적용 안내](docs/2차-진화-시범-적용.md)를 참고하세요.

v0.2.0에서는 바탕화면 무한 라운드 디펜스를 추가했습니다. 오른쪽 아래 1~5번 칸에 드래그로 편성하고, 자동 공격·클릭 스킬·Shift+클릭 표식 토글로 전투합니다. 라운드 완료마다 무작위 강화 카드 3장 중 1장을 선택하며 강화는 해당 전투에서만 유지됩니다. 31종 공격·스킬 이펙트와 6종 적 이동 애셋을 ZIP에 포함했습니다. 고구마 우클릭으로 능력치·특성·스킬을 확인하고, 시작 이미지는 클릭해 스킵할 수 있습니다. 축소된 화면 크기에 맞춰 충돌 판정도 조정했습니다. [디펜스 사용 안내](docs/디펜스-구현-사용안내.md)를 참고하세요.

v0.1.18에서는 성체 30종과 간첩마의 수정 프레임을 기존 애셋 경로에 적용했습니다. 아기 고구마 디자인은 유지합니다. 고구마 행동 메뉴의 **맛탕 만들기**를 선택하고 확인하면 해당 개체와 돌봄 기록을 삭제합니다. 추억 앨범에는 남지 않으며, 도감·씨앗·공용 가방은 유지합니다.

일부 프레임은 정상 컷 재사용으로 동작이 축약되며 원본 대비 윤곽·무늬 차이가 남습니다.

v0.1.17에서는 바탕화면 캐릭터를 기존 크기의 70%(84×84픽셀)로 축소했습니다. 클릭 영역·말풍선·이름표와 공 출발점·회수 위치·충돌 범위도 맞춰 조정했습니다. 땅속 집 화면의 캐릭터 크기는 유지합니다.

v0.1.16에서는 훈련 종료 후 공·골대가 남는 문제를 수정했습니다. 종료 시 기록 패널만 유지하며, 조준 궤적 미리보기는 기존 약 1/6 길이로 줄였습니다. 실제 투척 파워와 최대 거리는 유지합니다.

골인 훈련은 가까운 거리 3회 → 먼 거리 5회 → 최대 거리 7회로 이어집니다. 각 단계에서 전부 골인하면 다음 단계가 열리며 골인당 씨앗은 1·2·3개입니다. 기본 완료 보상 8개는 첫 단계에서만 기존 쿨타임에 따라 지급합니다. 골대 높이는 매번 달라지고 공이 상단 선에 닿으면 골인입니다. 화면 가장자리에서도 최대 파워를 낼 수 있도록 당기기 범위를 보정합니다.

좌측 상단에 누적 골인 점수와 개인 최고 기록(15점 만점)을 표시하고, 종료 후 기록 화면을 캡처할 수 있습니다. 공 가져오기에서는 다른 활성 고구마에 공이 맞으면 종류별 대사와 모션으로 반응하고 공이 튕깁니다. 캐릭터 클릭 시 공이 뒤로 가려지는 표시 순서도 수정했습니다.

놀이·훈련·쓰다듬기 쿨타임은 3분입니다. 쓰다듬기는 피로 +1, 골인은 쿨타임과 무관하게 즉시 씨앗 +1이며 훈련 완료 기본 보상은 씨앗 8개입니다.

나이와 성장 경험치를 별도로 저장합니다. 자동 성장 경험치는 활성 실행 분당 1 EXP이며 180 EXP에서 성장 준비 상태가 됩니다. 성장 영양제는 씨앗 30개로 구매하고 아기 행동 메뉴에서 먹이면 +30 EXP입니다. 영양제는 나이와 100시간 수명을 변경하지 않습니다.

이전 Version 1·2 저장 파일은 자동 전환하며 기존 나이·성체·성장 준비 후보를 유지합니다. 새 저장 형식(Version 3)은 이전 EXE와 호환되지 않으므로 업데이트한 EXE를 사용하세요. 저장 시 이전 파일은 save.json.bak에 보관합니다. 기존 Version 2 저장은 디펜스 기록 필드가 없어도 읽을 수 있습니다.

아기고구마와 성체 31종의 먹기·치료·쓰다듬기·혼잣말·놀이·훈련·청소·인사·공 맞기·디펜스 스킬·상태 요청 반응을 성격에 맞게 구분했습니다. 각 상황마다 기존 멘트에 3개를 추가해 4개를 무작위 순서로 한 번씩 표시하며, 직전 멘트는 연속해서 나오지 않습니다. 대사 순서는 실행 중에만 유지합니다. [캐릭터별 전체 멘트 표](docs/캐릭터별-상호작용-멘트.md)를 참고하세요. 배고픔 등 수치 변화는 메뉴에서 확인하며 간첩마의 말투는 직접 작성한 대사에만 적용합니다.

## 실행

배포 ZIP 전체를 압축 해제한 뒤 `GuMaGoChi.exe`를 실행합니다. `assets` 폴더는 EXE와 함께 유지합니다. Windows 10/11과 .NET Framework 4.8 이상을 사용합니다.

고구마를 우클릭해 돌봄·놀이·훈련·집·개체 활성화를 선택합니다. 몸을 바로 드래그하면 위치를 옮길 수 있습니다. 쓰다듬기는 우클릭 메뉴에서 선택합니다. 고구마는 혼자 걷고 잠깐 쉬며 방향을 바꿉니다. 트레이 아이콘에서 집을 열거나 전체 일시정지·종료할 수 있습니다. 상세 안내는 [사용안내.txt](사용안내.txt)를 참고하세요.

## 구현한 기능

- 투명한 항상 위 창, 화면 아래 생활, 개체별 위치 이동, 전체 화면·절전·잠금 시 일시정지
- 공통 아기, 기존 30종 성체, 성격·대표 특기, 기록 기반 후보 제외·가중 확률 성장
- 180 EXP 성체 성장(자연 누적 3시간), 흙더미 대기와 결과 사전 확정, 정확히 100시간 수명·질병 사망
- 배고픔·청결·피로·병세, 무료·유료 돌봄, 공통 쿨타임, 직접 청소·수면
- 씨앗·공용 가방·입양·구매, 선택한 여러 개체 활성화, 전멸 시 무료 재시작
- 바탕화면 공 가져오기·고구마가 직접 쏘는 3회 골인 훈련
- 텍스트 혼잣말, 근접 인사와 친분, 순차 대화
- 공용 땅속 집·개체 관리·도감·추억 앨범·트레이 돌봄 표시
- 자동 저장·이전본 백업·저장 데이터 내보내기/가져오기·선택적 자동 실행
- 바탕화면 무한 라운드 디펜스, 수직 5칸 편성, 31종 스킬·6종 적, 카드 강화, 최고 기록·씨앗 보상

**현재 한계:** 신규 아기에는 이동·식사·공 발사·땅속 성장 준비 시트를 적용했습니다. 대기·수면은 기준 이미지와 기본 표현을 사용합니다. 성체 30종은 아기 디자인 기반 신규 정면 이미지와 전용 이동·먹기·공 발사·땅속 들어가기 시트를 사용합니다. 아기와 성체 수면은 눈을 감은 전용 4프레임 시트입니다. 성체 전용 포즈 시트, 다양한 관계 행동, 3단계 성장, 집 꾸미기는 후속 개발입니다. 성격별 대사와 수치 균형은 추가 보완이 필요합니다.

## 저장과 시간

`%LOCALAPPDATA%\GuMaGoChi\save.json`에 저장하며, 이전본은 `save.json.bak`입니다. 프로그램 폴더를 옮겨도 같은 윈도우 계정의 기록은 유지됩니다. 온라인 서버나 계정은 필요 없습니다.

활성 개체만 나이를 먹습니다. 수면은 나이에 포함하고, 종료·절전·잠금·전체 화면·비활성·성장 대기는 멈춥니다. 집 창을 닫아도 활성 개체의 시간은 계속 흐릅니다.

## 개발과 검증

외부 패키지 없는 C# / .NET Framework Windows Forms 프로그램입니다. 윈도우에 포함된 Framework C# 컴파일러를 사용합니다.

```powershell
./build.ps1     # bin/GuMaGoChi.exe
./test.ps1      # 모델·대사·진화·달리기·점심 사다리 검사 + UI·744개 프레임·디펜스 렌더링 검사
./package.ps1   # release/GuMaGoChi-0.2.2-windows.zip
```

테스트와 렌더링은 고정 테스트 개체를 사용하며 실제 육성 저장 파일을 변경하지 않습니다. `bin/home-preview.png`와 `bin/sprites-preview.png`로 렌더링 결과를 확인할 수 있습니다.

| 파일 | 역할 |
| --- | --- |
| `src/Model.cs` | 상태·성장·수명·재화·저장 |
| `src/Desktop.cs` | 투명 캐릭터 창·트레이·실행 시간·메뉴·대화 |
| `src/Home.cs` | 땅속 집·관리·가방·상점·도감·추억·백업 |
| `src/Activity.cs` | 공 물리·회수·골인 훈련 |
| `src/Program.cs` | 진입점·자동 검증·화면 렌더링 |

## 다른 PC에서 Git으로 실행

저장소 루트의 GuMaGoChi.exe와 assets 폴더를 함께 Git에 포함합니다. Windows에서 git clone 후 루트의 GuMaGoChi.exe를 실행하면 최신 디자인을 사용합니다. 업데이트는 프로그램을 종료하고 git pull 후 다시 실행합니다. .NET Framework 4.8이 필요하며 다른 PC의 육성 저장은 해당 PC에 별도로 생성됩니다.

## 간첩마

v0.1.12부터 31번째 성체 성장 후보에 간첩마를 추가했습니다. 둥근 감자가 가짜 새싹을 붙여 고구마 행세를 하며 대표 특기는 집중입니다. 전용 정지·걷기·먹기·발사·수면·땅속 들어가기 시트를 하나의 공통 배율로 표시합니다. 기존 성체는 유지되고 새 아기가 성장할 때 후보에 포함됩니다.

신규·기존 이용자 모두 첫 실행 시 성장 영양제 6개를 1회 받습니다. 기존 영양제에 추가되며, 지급 여부는 저장 데이터에 기록되어 재실행이나 추가 입양으로 중복 지급되지 않습니다.
