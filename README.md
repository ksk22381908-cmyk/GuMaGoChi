# GuMaGoChi

윈도우 바탕화면에서 키우는 고구마 다마고치. 현재 기획 단계입니다.

- [기획서](docs/GuMaGoChi-기획서.md): 확정 규칙, 캐릭터 성격·특기 초안, 미정 항목과 확장 계획
- [디자인 에셋](assets/higgsfield/): 성체 캐릭터 30종, 배경 12종, 이펙트와 원본 시트
- [에셋 목록](assets/higgsfield/manifest.json)
- [캐릭터 전체 미리보기](assets/higgsfield/source/characters-preview.jpg)

공통 아기는 신규 제작 예정이며, 현재 캐릭터 에셋은 정면 정지 포즈입니다. 실행 프로그램은 아직 포함하지 않습니다.

## 에셋 구성

`characters/00.png`부터 `29.png`까지 기획서의 성체 후보에 대응합니다. 배경과 이펙트는 기존 디자인 자료이며, 새 프로그램에서의 사용 범위는 추후 결정합니다. 기존 에셋 README에 있는 전투·게임 적용 설명은 이전 프로젝트의 제작 기록입니다.

`preview.html`은 로컬 브라우저에서 열어 에셋을 확인할 수 있습니다.
